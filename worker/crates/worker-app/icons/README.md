# icons

Generated by `cargo tauri icon path/to/logo.png` from the repo-root `logo.png`.

**Only the four files the bundle actually consumes are committed** — `../tauri.conf.json`
lists `32x32.png`, `128x128.png`, `icon.icns` and `icon.ico`. `cargo tauri icon` also emits
full Android and iOS icon sets and the Windows Store `Square*Logo` variants; this project has
no mobile target and does not ship to the Store, and carrying them cost ~2 MB of the
repository for files nothing read.

If you regenerate, delete everything the config does not list before committing.

`cargo tauri dev` runs without any of them.
